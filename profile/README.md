**Legit Labs** is the open-source home of [Legit Security](https://www.legitsecurity.com/) — the AI-native ASPM platform that detects, fixes and prevents AppSec risk from AI-generated code, secrets and critical vulnerabilities, from prompt to cloud.

Here we build in the open:

- [**legitify**](https://github.com/Legit-Labs/legitify) — detect and remediate misconfigurations and security risks across your GitHub and GitLab assets · [`gh` extension](https://github.com/Legit-Labs/gh-legitify) · [Homebrew tap](https://github.com/Legit-Labs/homebrew-legit-labs)
- [**legit-provenance-generator**](https://github.com/Legit-Labs/legit-provenance-generator) — language-agnostic SLSA provenance for GitHub Actions
- [**supply-chain-playbooks**](https://github.com/Legit-Labs/supply-chain-playbooks) · [**trivy-remediation-playbooks**](https://github.com/Legit-Labs/trivy-remediation-playbooks) — hands-on remediation guides
